# Legal review notes — Skill Arcade demo

## Current prototype
This package uses demo credits only. Demo credits cannot be deposited, withdrawn, sold, transferred or redeemed.

The proposed commercial concept is a multi-game competitive skill arcade with fixed-entry lobbies, a disclosed platform fee and placement-based prizes. The prototype currently shows $1 / $5 / $20 example lobby amounts only to demonstrate the intended UX and economics.

## Proposed economics shown in demo
- Platform fee: 5% of gross entries.
- Remaining 95% is the displayed prize pool.
- Only the top three placements receive a prize in the standard lobby model.
- Each game defines objective placement rules before the match starts.

## Games included for review
1. Floor Breaker — survival / aiming / movement.
2. Obstacle Sprint — obstacle-course racing.
3. Knockout — position / movement / dash knockback.
4. Bomb Tag — movement / tag timing / survival.
5. Falling Tiles — movement / route planning / survival.
6. Red Light Run — reaction / movement timing / racing.
7. Coin Rush — movement / route selection / score collection.
8. Safe Zone — reaction / movement / survival.
9. Wall Dodge — lateral movement / reaction / survival.
10. Maze Rush — navigation / movement / racing.
11. Meteor Dodge — movement / reaction / survival.

## Questions for counsel
- How are these contests classified in each proposed player jurisdiction?
- Does an entry fee plus placement-based cash prize require a gaming/gambling/contest licence even where outcomes are predominantly skill-based?
- Which jurisdictions should be excluded or geofenced?
- What age restrictions and identity checks are required?
- What payment/custody structure is permitted, and should player money be held by a licensed third party?
- What AML/KYC obligations apply to deposits and withdrawals?
- What consumer disclosures, contest rules, responsible-play controls and dispute processes are required?
- Are any specific mechanics (random map selection, equal-condition random events, tie breakers, bots, matchmaking) legally material?
- What corporate entity and operating location are appropriate?

## Before any real-money launch
The production version would need an authoritative multiplayer server, anti-cheat, identity/age verification, geolocation, jurisdiction gating, transaction ledgers, approved payment/custody infrastructure, fraud/collusion monitoring, formal contest rules, audit logs and professional legal review.
